# Security and Privacy

## Public repository

Nicole Portfolio is intentionally public. Every committed file must be safe for anonymous access.

## Never commit

- Passwords, tokens, API keys, recovery codes, or private keys
- `.env` files or deployment credentials
- Private Nicole Universe records, admin code, uploads, backups, or exports
- Personal addresses, phone numbers, private email addresses, or identity documents
- Unapproved photographs or files containing location metadata

## Reporting

Do not include credentials or personal data in a public GitHub issue. Use GitHub’s private security-reporting channel if it is enabled.
