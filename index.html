04 / Learning Platform

Personal project · Jul 2026–Present · JavaScript

Ana Tilim / Uyghur Tili

Designed and developed a two-edition, mobile-first Uyghur language learning platform for phones, tablets and desktop computers: Ana Tilim for global learners and Uyghur Tili for China-based access.

Challenge

Deliver a consistent multilingual curriculum across two deployment environments while preserving different authentication, storage and external-dependency requirements.

My Role

Defined product requirements and course architecture, structured multilingual content and human audio, implemented learning interactions, and coordinated edition-specific releases and verification.

Approach

Built shared right-to-left learning logic, Uyghur keyboard practice, listening, syllable training, reading activities and portable learning progress. Ana Tilim supports optional authentication and UID-scoped Supabase sync, while Uyghur Tili removes login and cloud sync, stores progress locally and deploys through Tencent CloudBase.

Outcome

Released two live editions: a 12-unit global curriculum and an 11-unit China edition, supported by automated checks covering course data, transliteration, audio, progress, configuration boundaries and full-content rendering.

Evidence Produced

Edition configurations, shared course data, audio manifests, local and cloud progress designs, public repositories and deployment-specific QA.

Skills Applied

Product requirements, business rules, configuration management, data quality, multilingual UX, accessibility, privacy by design, Supabase, RLS, CloudBase, test automation, HTML, CSS and JavaScript.

Global edition · China edition · Ana Tilim GitHub · Uyghur Tili GitHub
