03 / Data & AI

COMPX500 Project 1 · A+ · Aug–Sep 2025 · AI application study

Harry Potter Knowledge Assistant

Explored a scoped knowledge assistant through multi-source knowledge organisation, a librarian persona, answer boundaries and source-aware response review.

Challenge

Improve answer consistency while making data sources, uncertainty and off-topic boundaries explicit.

My Role

Worked on knowledge organisation, the librarian persona, answer scope and citation rules, response review, and comparison of cloud and local approaches.

Approach

Organised material from Wikipedia, Kaggle and Fandom using subject tables and aliases. Defined how the assistant should handle sources, uncertainty and off-topic questions, and compared responses qualitatively.

Outcome & Scope

The project CSV contains 16,245 rows of data, not 16,245 independently verified facts. The report records qualitative observations rather than a measured accuracy improvement. This was an academic AI application study, not model training or a production-grade retrieval system.

Supporting Evidence

Notebook, CSV tables, report, persona instructions and cloud/local comparison. The Python notebook is a project artefact, not evidence that I independently wrote every part of its code.

Skills Applied

Knowledge organisation, source review, answer constraints, qualitative AI evaluation, comparative analysis and documentation.

04 / Learning Platform

Personal project · Jul 2026–Present · AI-assisted implementation

Ana Tilim / Uyghur Tili

Defined the learning path, language-content direction and interface requirements for a two-edition Uyghur learning platform for phones, tablets and desktop computers, with code implemented primarily by Codex.

Challenge

Make Uyghur learning activities usable across screen sizes and language directions, while accounting for the different access requirements of global and China-based learners.

My Role

Defined intended learners, learning order, language-content direction, keyboard and interaction requirements, and the audio recording and review workflow. Made feature trade-offs, reviewed content and interfaces, and requested and checked revisions.

Approach

Shaped requirements for alphabet and connected-script practice, listening, reading, writing, vocabulary, grammar and learning progress, including right-to-left text and Uyghur keyboard use.

Implementation

Code is implemented primarily by Codex. Ana Tilim and Uyghur Tili are global and China-focused editions of one product family.

Outcome & Scope

The project includes learning activities, progress features and an audio review workflow. Content preparation and review are ongoing; not all learning material or audio has completed review.

Supporting Evidence

Product requirements, interface iterations, course content, keyboard behaviour, audio review workflow and the two edition repositories.

Skills Applied

Product requirements, learning-path design, multilingual UX, content organisation, audio review requirements, feature prioritisation and manual acceptance checks.

Global edition · China edition · Ana Tilim GitHub · Uyghur Tili GitHub
